# pocod-git-github

Учебный репозиторий по дисциплине «ПО ЦОД» — лабораторные работы №1 (Git) и №2 (совместная работа в GitHub).

Содержимое: небольшой калькулятор мощности стойки ЦОД на Python.

## Функции

| Функция | Назначение |
|---|---|
| `rack_power` | мощность стойки, кВт |
| `rack_heat_btu` | тепловыделение, BTU/ч |
| `pue` | показатель энергоэффективности ЦОД |

Запуск тестов: `python3 -m unittest discover -s tests -t .`
